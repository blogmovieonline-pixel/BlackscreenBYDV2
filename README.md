# ล็อกจอกันมือลั่น

แอปสำหรับจอแอนดรอยด์ในรถ กันคนมือลั่นแตะมั่ว

## โหมด
- **ล็อกแบบโปร่งใส** วางชั้นใสทับจอ ยังเห็นแผนที่/กล้องถอย แต่สัมผัสไม่ติด
- **ล็อกแบบจอดำ** จอดำทั้งหมด สัมผัสไม่ติด
- **ล็อกเต็มจอ** ซ่อนแถบบน/ล่างเหมือนดูวิดีโอ + ตรึงแอป (จอดำ) ระบบอาจถามยืนยันการตรึงแอป

## ปลดล็อก
แตะ 5 ครั้งติดกัน ภายใน 4 วินาที ที่มุมขวาบนของจอ (กรอบประมาณ 1.5 นิ้ว)
ปุ่มฮาร์ดแวร์ เช่น ปุ่มที่พวงมาลัย ยังทำงานตามปกติ

## ใช้ครั้งแรก
กดโหมดที่ต้องการ แอปจะพาไปหน้าตั้งค่า ให้เปิด "แสดงทับแอปอื่น" แล้วกลับมากดอีกครั้ง

## สร้างไฟล์ .apk ด้วย GitHub
1. สร้าง repository ใหม่บน github.com
2. อัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ .github)
3. แท็บ Actions → Build APK → รอ 3-5 นาที
4. ดาวน์โหลด Artifact BlackScreenLock-apk (ข้างในคือ app-debug.apk)

หรือเปิดโฟลเดอร์ด้วย Android Studio แล้ว Build → Build APK(s)

## ข้อควรระวัง
- ไม่ควรใช้โหมดจอดำขณะขับ เพราะบังกล้องถอยและตัวควบคุมแอร์
- ยังไม่ได้ทดสอบบนจอรถจริง
